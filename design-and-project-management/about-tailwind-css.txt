How to start with Tailwind CSS?
===============================
There seems to be a few options:

1. Django + Tailwind CSS + Flowbite
https://flowbite.com/docs/getting-started/django/

Flowbite is open source library of UI components (buttons, drop-downs, navbars) based on top of Tailwind CSS framework
Source: 
https://flowbite.com/docs/getting-started/introduction/


2. Django-Tailwind + Cookiecutter + Honcho + Reload
Installation: https://django-tailwind.readthedocs.io/en/latest/installation.html

* cookiecutter is open source command line utility for creating projects. It provides templates = "cookie cutters"
Source:
https://www.port.io/glossary/cookiecutter#:~:text=Cookiecutter%20is%20an%20open%2Dsource,known%20as%20%22cookie%20cutters%E2%80%9D.

* honcho is a Python library/API for running a few processes at the same time.
E.g.Django and Tailwind servers can run simultaneously with $ python manage.py tailwind dev
Source:
https://honcho.readthedocs.io/en/latest/

* django-browser-reload is a package that automatically reloads the page during development
Source:
https://pypi.org/project/django-browser-reload/


3. Tailwind CLI
https://tailwindcss.com/docs/installation/tailwind-cli
Tutorial by Piko can fly: https://www.youtube.com/watch?v=XQECGEjOo4M

--2 Follow the official tailwind css documentation for Tailwind CLI Installation - it is STEP [01]

--3 Create static folder with src folder in the project directory/where manage.py is located: static/src
--4 Create styles.css in static/src
--5 Add static folder reference to settings.py 
    STATICFILES_DIRS = [BASE_DIR / "static"]
--6 Paste import statement from the official docs into the styles.css 
It is STEP [02] in Tailwind CSS documentation

--7 Follow STEP [03] in Tailwind CSS documentation
Run CLI tool that will scan files searching for classes and will build the CSS
$ npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch

Can add this command as a script to package.json
"scripts" : {
    "watch:css" : "npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch"
}
input [./src/input.css] needs to be replaced with the actual location of the css file
output [./src/output.cs] needs to be replaced with the planned location of the output file 

Run a command: $ npm run watch:css

--8 Follow STEP [08] in Tailwind CSS documentation - link stylesheet in HTML
!Note that the stylesheet that is linked in the HTML is for the output.css not input.css!
